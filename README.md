# Instuction on how to run project

1. Clone repository
2. Change Directory in to the backend folder
3. Copy `.env.example` file as `.env` then provide your `OPEN_API_KEY`
4. type `npm run dev` in termnial to run the backend project
5. open another terminal, change directory to the client folder
6. type `npm run dev` in termnial to run the client project
7. happy chatting with the bot!!!!
